# About 冒頭3セクション — デザイン試作

2026-10-12 / Issue #133。HERO → WHY → OUR ROLE を一続きの体験として設計した比較用の試作。見出しと本文は検討用。採用する案を確認してから本番の実装範囲を決める。

## 確認方法

リポジトリのルートで以下を実行する。既存のプレビューサーバーは共通ナビの拡張子なしURL（`/about` など）も解決する。

```sh
python3 tools/preview-extensions.py --port 8768
```

[比較画面](http://127.0.0.1:8768/prototypes/about-2026/index.html)で案と画面幅を切り替える。PCは1440×1000、スマホは390×844の実際のレイアウト幅を持つiframe。枠内でスクロールでき、外側の画面が小さいときはプレビュー全体を縮小する。「別タブで開く」では閲覧端末の幅で表示する。

- [A：エディトリアル](a.html) — 白と余白、大きなコピー。左の細い線が3章を通り、HEROの青・オレンジの軌跡が事業の接続へ続く。落ち着いた信頼感が強み。派手さは控えめ。
- [B：ストーリー](b.html) — PCでは一つの図が横に残り、理念 → 未接続 → 2つの力による接続へ変わる。スマホでは通常フローの図と縦の線で読む。理解の流れを重視。PCは読む距離が長め。
- [C：ブランドビジュアル](c.html) — オレンジの面と青い輪、全章を包む一枚の淡い背景。離れた図形がつながる意味を反復する。印象が強み。抽象図形と説明のバランスに注意。

各案の末尾にも切替リンクがある。`screenshots/` に1440pxと390pxの全ページPNGを収録（Bの静止画は初期状態。図の変化はHTMLで確認）。

## 共通のストーリー

1. **00 HERO** — 「きっかけがあれば、人も企業も、輝く。」で理念を提示。
2. **01 WHY** — 技術やサービスを持つ企業が必要とする相手に出会えていない。人の才能も同じ。価値の不足より接点の不足が背景にある。
3. **02 OUR ROLE** — Creative Xが価値を伝わる形にし、Sales Xが必要な相手への接点と営業の仕組みをつくる。両方を持つ理由を示す。個別サービスの詳細は扱わない。

## 実装の境界

- 本番の `about.html`・`index.html`・`recruit.html`、共通CSS/JS、ナビ定義を変更しない。
- 既存の `style.css` と `sitewide-cohesion.css`、ブランドトークンを読み込み、共通ヘッダーとロゴを使用。`i18n.js` → `nav.js` の順序を維持する。試作固有の文章に `data-ja` / `data-en` を付与。
- ページ固有のCSSは `ap-*`、比較画面は `apr-*` に限定。新しいブランド色や書体を導入しない。小さいオレンジ文字は既存の `--cx-color-creative-text` を使う。
- 図形はCSS/SVG、文章はすべてHTMLテキスト。画像生成は不要と判断。画像にコピーを埋め込まない。
- Bのスクロール監視はpassive + requestAnimationFrameで補助図と目次の状態を更新。スクロールのロック、スナップ、本文の非表示、常時アニメーションは使わない。
- `prefers-reduced-motion: reduce` ではトランジションとsmooth scrollを無効化し、Bのstickyも解除する。JS無効でも本文・2事業の説明・切替リンクは表示。
- 本番計測タグ、送信フォーム、WPアクセスを読み込まない。試作ページは `noindex,nofollow`。本番ナビとsitemapに追加しない。
- `base href="/"` は共通nav.jsの既存相対リンクをルート基準に解決するため。本試作はHTTPサーバーのルートから確認する。
