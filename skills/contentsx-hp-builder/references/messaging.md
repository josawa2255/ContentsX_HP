# Messaging Rules (ContentsX / BizManga)

## 1. 禁止・推奨表現

- 禁止: `AI漫画`, `AI生成漫画`
- 推奨: `次世代ニューマンガ`, `次世代ハイブリッド漫画`
- 非推奨: 旧タグライン `伝えるを、再発明する。`

## 2. 主要訴求

- 人間の創作力7割 + AI技術3割
- ネーム・シナリオは人が主導
- 単なる制作受託ではなく課題発掘型コンサルティング

## 3. 代表的な数値（改変禁止）

- CVR: 5.4倍
- CTR: 最大25倍
- 研修時間: -80%
- コスト: 従来比1/5
- 納期: 最短2週間
- PV: 40倍
- CPA: 約1/3

## 4. トーン

- B2B向けに簡潔・論理的・実証重視で書く。
- 誇張よりも実績と導入効果を優先する。
- 断定が難しい内容は「想定」「目安」と明記する。
