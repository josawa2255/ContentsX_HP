ビズセールスナビ

営業の「次に何をするか」まで面倒を見る、法人向けの営業管理サービス

ビズセールスナビは、会社・担当者・案件・商談の記録をひとつにまとめ、AI が議事録の作成や次の行動の提案を手伝う、法人向けの営業管理（CRM）サービスです。提供は Contents X 株式会社です。

できること

  • 顧客と案件の管理: 会社・担当者・案件・活動（商談・電話・メール）を記録し、チームで共有します
  • 日程調整: 予約ページを送ると、相手が空いている時間を選んで予約できます。予約は担当者の Google カレンダーに予定として入り、Google Meet の URL も自動で用意します
  • 議事録: Google Meet の会議のメモから議事録を作り、案件や担当者にひも付けます
  • AI の提案: 商談の前の準備や、次にやるべきことを AI が提案します。メールの送信など外への働きかけは、利用者の操作か、会社が許可した設定にもとづいてだけ行います
  • メールの履歴: 担当者とのメールを Gmail から取り込み、相手ごとのやり取りをまとめて見られます。AI が要約や返信の下書きを手伝います
  • お問い合わせの受付: 自社のホームページのフォームからの問い合わせを受信箱に集めます

Google アカウントとの連携について

ビズセールスナビは、利用者が設定画面で許可したときにだけ、Google のサービスと連携します。

小さい画面では表を横にスクロールしてご覧ください。

連携するもの使い道
Google カレンダー予定の表示、日程調整の空き時間の計算、予約や商談の予定の作成・変更
Google ドキュメント（読み取り）会議に添付された Google Meet のメモから議事録を作る
Google Meet の会議の設定招待した相手が承認なしで会議に参加できるようにする
Gmail（読み取り）登録した顧客・取引先とのメールだけを取り込み、メールの履歴・要約・返信の支援に使う（それ以外のメールは保存しない）
Gmail（送信）予約のお礼や商談のリマインドを、利用者本人の Gmail から送る
  • Google のデータは、上の機能のためにだけ使います。広告には使わず、販売もしません。AI のモデルの学習にも使いません
  • ビズセールスナビによる、Google API から受け取った情報の使用と他のアプリへの転送は、Limited Use の要件を含む Google API Services User Data Policy に従います
  • 連携はいつでも設定画面から解除できます。詳しくはプライバシーポリシーをご覧ください

法人でのご利用

Google Workspace の管理者が外部アプリの利用を制限している場合、管理者がビズセールスナビを許可するまで連携できません。管理コンソールの「セキュリティ → アクセスとデータ管理 → API の制御 → サードパーティ製アプリのアクセスを管理」から、ビズセールスナビを許可してください。
