EVERYDAY WORK

こんなときに、TabLabo。

  • 01

    朝いちばんに、CRM・スプレッドシート・チャットを毎回ひとつずつ開いている

  • 02

    商談の前に、提案資料や料金表のタブを探している

  • 03

    新しく入ったメンバーに「このページとこのページを開いて」と毎回教えている

FEATURE 01

1 クリックで、決まった順番にまとめて開く

Workspace をクリックするだけで、登録した URL が確認なしで順番どおりに開きます。開いたタブは Workspace の名前のタブグループにまとまり、最初に見たいタブ（Startup Tab）が前面に出ます。新しいウィンドウで開くこともできます。

FEATURE 02

自分の Workspace を、かんたんに作る

URL の追加・並べ替え（ドラッグ＆ドロップ）・複製ができます。いま開いているタブから、そのまま Workspace を作ることもできます。同じ Google アカウントなら、別のパソコンでも同じ Workspace を使えます。

FEATURE 03

チームで同じ仕事環境を共有する

会社のドメインで組織に参加すると、管理者が用意した Workspace をメンバー全員が 1 クリックで使えます。管理者が変更すれば、次に開いたときから最新になります。社外の方（Gmail など）も招待できます。部署（Team）ごとに配る Workspace を分けることもできます。

FEATURE 04

会社の Workspace を、自分用に少しだけ変える

会社の Workspace に自分だけのタブを足したり、使わないタブを自分だけ非表示にしたり、開く順番や最初に見るタブを変えたりできます。会社の Workspace そのものは変わりません。

PRIVACY FIRST

安心して使える

  • Web ページの中身や閲覧履歴は読み取りません
  • 必要な権限は最小限です（タブの読み取りは「いまのタブから作る」を使うときだけ許可を求めます）
  • 自分で作った Workspace や自分用の設定は、組織の管理者にも見えません
  • Google アカウントでログインします（メールアドレス・名前・プロフィール画像だけを使います）

FOR ORGANIZATIONS

法人でのご利用

Google Workspace の管理者が外部アプリの利用を制限している場合、管理者が TabLabo を許可するまでログインできません。

管理コンソールの「セキュリティ → アクセスとデータ管理 → API の制御 → サードパーティ製アプリのアクセスを管理」から TabLabo を許可してください。導入のご相談はお問い合わせからどうぞ。
